# Pages

Pages è un host leggero, privato ed elegante per siti web statici progettato specificamente per umbrelOS.

Combina un pannello di controllo pulito, una libreria integrata di 9 template, un editor di codice web, backup locali e pubblicazione flessibile su rete locale, domini personalizzati, Tor condiviso di Umbrel o un indirizzo Onion v3 completamente indipendente per ciascun sito.

## Caratteristiche

- Gestione di siti web statici multipli e indipendenti.
- Dashboard di riepilogo con siti pubblicati, bozze, visualizzazioni, spazio su disco, backup e stato di Tor.
- Sezioni dedicate: **Sites**, **Templates** e **Settings**.
- 9 template responsive pronti all'uso, leggeri e privi di risorse o script di terze parti.
- Anteprima live istantanea di ogni modifica.
- File manager ed editor di codice integrati nel browser.
- Caricamento di file singoli, intere cartelle e archivi ZIP.
- Esportazione in formato ZIP e backup locali ripristinabili.
- Indirizzi locali e Tor Umbrel automatici.
- Generazione opzionale di un'identità Onion v3 indipendente e dedicata per ogni singolo sito web.
- Routing per domini personalizzati tramite header HTTP `Host`.
- Supporto per SPA fallback, CORS configurabile, directory listing e policy di caching.
- Contatori di visite locali nel pieno rispetto della privacy (nessun cookie/tracker).
- Autenticazione integrata con password protetta.
- Database di configurazione SQLite locale.
- Supporto multi-architettura nativo per `linux/amd64` e `linux/arm64`.
