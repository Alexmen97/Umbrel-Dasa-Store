This repository contains the custom **🅳🅰🆂🅰™ Umbrel Community App Store**. 

Unlike the official store, this one is entirely community-driven and independently maintained. It offers curated, tested, and multi-architecture Docker apps for your Umbrel server. All applications include verified manifests, pinned Docker images, and reverse-proxy configurations.

🔀 We are open to app suggestions and will do our best to implement them! Feel free to open an issue or request a new application.

---

### ⚠️ How to add the App Store:

1. Open your Umbrel web dashboard (e.g. `http://umbrel.local`).
2. Open the **App Store**.
3. Click the three dots menu (**⋮**) in the top right corner and select **Community App Stores**.
4. Paste the URL of this repository:
   ```text
   https://github.com/Alexmen97/Umbrel-Dasa-Store
   ```
5. Click **Add**.
