Il tuo server di agenti AI

Questa è la pagina di configurazione del pacchetto Umbrel, non il client OpenBot e non un indicatore dello stato del server.

1. Associa il tuo account

In Umbrel apri Impostazioni → Impostazioni avanzate → Terminale → App → OpenBot Server. Seleziona il container server ed esegui:

openbot login

Inserisci personalmente email e codice nel terminale. Non condividere codici o credenziali in chat. Dal terminale host, in alternativa: docker exec -it dasa-openbot_server_1 openbot login.

2. Apri OpenBot e collega un provider

Accedi con lo stesso account e seleziona il server. Puoi usare anche l'app desktop o iPhone. Le chiavi e gli abbonamenti dei provider vanno configurati nel client.

Apri il client web OpenBot ↗

Questa immagine non serve una UI web locale: il client web e i servizi account/connessione remota sono esterni.

Controllo e backup

Nel terminale del server: openbot status. Per collegare l'app iPhone: openbot mobile-connect.

Prima del backup arresta l'app da Umbrel. Copia tutta la cartella data/openbot, inclusi file nascosti, keyring e relativa password. Non avviare due istanze con gli stessi dati. Gli aggiornamenti arrivano dallo store Umbrel.

Preview: usa solo attività fidate

Gli agenti possono eseguire comandi e modificare tutti i dati del container senza conferme per ogni azione. Il container può raggiungere la rete locale: applica regole firewall se necessario. Non aggiungere mount sensibili o il socket Docker.

Il server ha un limite RAM di 8 GB, di cui la memoria condivisa può usare fino a 2 GB. Computer Use, accesso remoto al desktop e alcuni login possono avere limitazioni; arm64 non include il runtime desktop remoto.
